# arity 上限

**状态**：候选
**一句话**：方法最多带 N 个参数（N 取 2 或 3），超过就要用记录。

**动机**：硬拦参数个数，把「散装参数」这个坏味道挡在编译期，而不是靠句法梯度劝。对以数据流为中心的语言，参数超过三个通常说明应该有一个记录类型——直接在语法上要求它，作者不会写出 `f a b c d e`。

**形态**（若采用）：

```
def clamp lo: Float hi: Float -> Float = ...     # 可以
def move x: Float y: Float z: Float -> ...       # 若 N=2：编译错误，改用 Point 记录
def move p: Point -> ...
```

**代价**：

- **拦不到根**：约束点是「接收者必须是聚合」，散参数靠句法梯度就够。硬拦会把 `rect x y w h` 逼成仪式化的记录加解构，反而更长。
- **一条硬规则要维护在错误信息里**，且和 `Fn` 的多元版本（多少元算多）冲突。
- **宿主边界**：`main args: List<Text>` 之类没问题，但宿主导出/导入的签名经常超限。
