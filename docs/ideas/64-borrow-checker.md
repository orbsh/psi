# borrow checker

**状态**：候选
**一句话**：引入引用与所有权，用编译期借用检查消除数据竞争与悬空，同时允许就地修改与零拷贝。

**动机**：不可变值语义把原地算法全部变成拷贝。Rust 证明了所有权 + 借用能在无 GC 的前提下同时给出内存安全和就地修改；对「脚本规模但也想跑数值/图像」的语言，这条路的性能上限高得多。

**形态**（若采用）：`&T` / `&mut T`、生命周期标注、移动语义；`[T]` 变成可变切片，`List` 可以有原地版本。

**代价**：

- **规格爆炸**：借用检查的规则（生命周期、NLL、可变借用的独占性）不是「一个人能读完」的量，而且错误信息要靠专门的诊断工程。
- **人体工学**：与「链式、无引用、值语义」的写法正面冲突——链上每一步都是临时值，借用检查器最不擅长的正是这种形态。
- **学习成本落在目标用户身上**：宿主脚本作者通常不是系统程序员。
