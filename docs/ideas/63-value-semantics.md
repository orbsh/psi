# 不可变值语义，无引用

**状态**：在用（可改）
**一句话**：值不可变；`mut` 只重绑槽，不改值；聚合的「更新」返回新值。没有引用类型、没有生命周期、没有所有权转移；闭包按值捕获。

**动机**：把别名问题整类消掉。没有别名，就没有 borrow checker 的对象，没有数据竞争，没有「谁负责释放」——[64](64-borrow-checker.md) 那一整章被划掉。

**形态**：

```
mut count: Int = 0
count = count + 1        # 重绑槽，不是改值

let c2 = c.with_radius 2.0   # 更新返回新值
```

- 核心数组 `[T]` 定长、构造后只读；prelude 的 `List` 是链式持久结构，prepend O(1)、索引 O(n)。
- 状态只有两处：模块级 `mut` 槽（单例状态）与宿主句柄。
- `"{x}"` 是 Text 插值，展开成 `Text.concat` 链，不引入新的求值机制。

**代价**：

- **大数组原地更新是 O(n)**：热循环不是 ψ 的场景，但「改一个元素的列表」也不便宜。`List` 索引 O(n) 让 `xs.[i]` 在长列表上变慢。
- **持久结构的内存放大**：链式 List 的共享尾部靠 GC 回收，短生命周期脚本里这层开销不小。
- **没有引用 = 没有高效的原地算法**：排序、原地变换只能返回新值。

**冲突**：[64](64-borrow-checker.md)（若引入引用，这套论证要重写）、[55](55-own-gc.md)、[56](56-hierarchical-arena.md)（区域模型的三项难点正以可变性与引用为前提，这里没有对象）。
