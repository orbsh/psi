# KDL 当表面语法

**状态**：候选
**一句话**：用 KDL（节点 + 位置实参 + 子块 + 属性）当语言的表面语法，源码就是数据，同像性免费。

**动机**：KDL 是人工可写的文档格式，解析器现成、缩进与嵌套规则现成，程序可以直接被程序读写成同一份文本。宏、格式化、LSP 全部省一层：不需要把语法树单独序列化成 AST 文本，源码本身就是表示。

**形态**（若采用）：

```
def "area" {
  self "Circle"
  -> "Float"
  body {
    mul 3.14159 (pow self.radius 2)
  }
}
```

**代价**（这是最实的一条）：

- **KDL 的值只有 string / number / keyword，节点不能作值**。要让操作数成树，只能升格为子块：深度原样而字符更多。
- **中缀与 arity 分组无处安放**。`a + b * c` 在 KDL 里是四个字符串实参，运算符不是语法，优先级也无处可写——这条直接和 [13](13-infix-by-spelling.md) 冲突。
- **同一串文本会被静默双读**。`let x: T = e` 读成实参 `x:` 加属性 `T=e`；`xs.map f.filter p` 会把点吞进标识符。
- **同像性要求的「一种读法」正是这条路给不了的**：KDL 的宽容（引号可省、属性与实参混排）让同一段文本有多种合法解析。

一个可用的折中：KDL 只当**声明层的外部表示**（宏的输入输出、编译器与工具之间的清单格式），不进表达式语法。声明层本来就是节点 + 位置实参 + 子块，与 KDL 同形；表达式层保持自己的文法。

**冲突**：[13](13-infix-by-spelling.md)、[12](12-arity-grouping.md)、[27](27-macros.md)（若宏存在，KDL 是声明清单的候选表示）。

**若改掉会动到**：整份文法、解析器、格式化器、[27](27-macros.md) 的载体选择。
