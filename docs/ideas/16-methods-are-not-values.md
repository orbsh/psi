# 方法不是值，函数只有块

**状态**：在用（可改）
**一句话**：方法是唯一可调用的声明形式，永远不是值；函数值只有一种形态——匿名块。因此没有柯里化，没有偏应用。

**动机**：让每个链步的含义只看写法就能定。`x.f` 只有一种读法：取这个成员并求值。如果方法可以当值，点上就同时有「取值」和「调用」两个含义，只能靠类型区分——那等于说 `.` 必须看类型才能读。

**形态**：

```
xs.map {x| x * 2}          # 要传变换，就写块
let normalize = {it.trim.lower}   # 想把一段行为存起来，也是一个块
d.map (a.x b.y c)          # 错：括号求出来的是值，类型不匹配
```

- 方法不是值：`Io.stdout.println` 单独成不了表达式。
- 高阶方法要的是函数，不是某条链的残段：要传变换写 `{it.x b.y c}`。
- 单参块的参数默认叫 `it`：`{it.trim}`。
- 组合是 `Fn` 上的方法，不是独立运算符：`normalize.then quote`。

**代价**：回调永远要多写一层块；`xs.map trim` 这种「直接把已有方法传进去」的便利不存在，得写 `xs.map {it.trim}`。对以高阶为主的语言，这笔钱很贵；对以链式数据变换为主的语言，它只落在少数位置。
