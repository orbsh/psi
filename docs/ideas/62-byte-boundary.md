# 边界只有字节

**状态**：在用（可改）
**一句话**：跨 wasm 边界可用的只有数值、线性内存和 `externref`，其余一律序列化；跨界不共享可变对象。

**动机**：wasm-gc 的 struct / array 是宿主不透明引用，没有跨边界共享可变对象的办法——而共享本来也不该有。每实例独立堆是「脚本改坏了不崩宿主」的前提，代价是复制，这对扩展脚本的调用频率可接受。

**形态**：宿主把参数序列化进线性内存，guest 读成 ψ 值；结果按同一格式回写。数值直传，`Text`/记录/枚举走编码（[44](44-text-repr.md) 的选择会影响这条的成本）。

**代价**：

- **大对象的每次调用都付一次拷贝**：把 10MB 的结构体传进脚本再传回来是 20MB 的 memcpy，且没有任何零拷贝路径。
- **没有对象身份**：宿主不能把一个句柄交给脚本再取回同一个对象，只能传 id/字节。
- **编码格式要定**：谁编谁解、版本怎么协商，是宿主契约问题，语言只管形状。

**冲突**：[44](44-text-repr.md)（自含表示让拷贝更贵）、[55](55-own-gc.md)（自建内存时可能想开共享）。

**若改掉会动到**：[61](61-three-hosts.md) 的三个导入表、[54](54-wasm-gc.md) 的隔离论证、[41](41-json-boundary.md)（Json 是跨界中转的候选格式）。
