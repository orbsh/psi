# Text 的表示

**状态**：未定
**一句话**：`Text` 到底是 wasm-gc 的 `array (mut i8)`（自含），还是宿主句柄（免拷贝），取决于字符串操作在脚本里的占比。

**动机**：这个选择决定了三件事——字符串操作的常数因子、跨宿主边界的拷贝次数、以及运行时 glue 的体积。

**形态**（两条路）：

```
# A：自含
Text = array (mut i8)            # 在 wasm 堆里，遍历/切片/比较都是本地操作
                                 # 跨边界要复制进/复制出线性内存

# B：宿主句柄
Text = externref                 # 只是宿主字符串的引用
                                 # 操作靠宿主导入，每次调用过一层边界
```

**代价**：

- **A 的代价**：跨边界复制。宿主传一个大 JSON 进来，先复制到 wasm 堆再解析；出去再复制一遍。中文/UTF-8 的索引、切片、字符边界规则要自己写。
- **B 的代价**：每个字符串操作都是一次宿主导入，`s.trim.upper.replace` 是三次跨界调用；宿主必须实现一整套字符串原语（三个宿主各一份），运行时 glue 不再接近零。
- **A 的中间代价**：内部用 A、边界用视图（`array (mut i8)` 指向线性内存的一段），避免复制但引入两套表示。

**冲突**：[54](54-wasm-gc.md)（内存模型的选择影响这条）、[62](62-byte-boundary.md)（边界只有字节，A 更自然）。
