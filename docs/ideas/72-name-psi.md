# 名字：ψ

**状态**：在用（可改）
**一句话**：语言叫 ψ（psi）——希腊字母里唯一同时挂着两个意象的：ψυχή（呼吸、灵魂）与量子力学里表示振幅的波函数。落盘一律 ASCII：`psi`、`script.psi`。

**动机**：轻、没有实体，但确实是场里的东西，与 `~/world` 家族的物理量命名（aura、effector、gravity）同域。名字要说的事：这门语言不是实体机器，是宿主场中的一份振幅。

**形态**：文档与讨论写 ψ；命令行、扩展名、仓库名、标识符一律用 `psi`。

**代价**：希腊字母在 shell 里打不出来，所有工具链与文件名必须用转写，于是「官方名」和「实际落盘名」永远是两个；`psi` 在搜索里与无数无关的东西撞（psi-* 包名很多）。

**冲突**：无。

**若改掉会动到**：README、仓库名、扩展名。
