# 全程序一个模块，没有链接器

**状态**：在用（可改）
**一句话**：全程序编译成一个 `.wasm`，没有对象文件、没有单独编译、没有符号解析、没有运行时加载 `.psi`。

**动机**：链接器是「多编译单元」的产物。全程序编译把这条整段砍掉：编译与实例化在同一次进程内完成，热重载 = 重编译重实例化，而重实例化正好是宿主侧最干净的隔离单位（脚本改坏了不崩宿主）。

**形态**：`psi run script.psi` 编译 + 实例化；宿主扩展模式是内嵌 runtime + 实例化 `.wasm`；缓存单位是整个模块。

**代价**：

- **增量编译不存在**：改一行重编译全程序。对千行级没问题，对十万行不成立——语言规模被这条选择限住。
- **库的复用靠源码而不是产物**：没有 `.rlib` 一类中间产物，导入一个库就是再编译一遍它的源码。
- **没有动态链接**：宿主不能把多个编译好的脚本模块拼起来（除非在 wasm 层做多模块链接，那是把链接器请回来）。
