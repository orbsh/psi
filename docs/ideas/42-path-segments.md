# Path 是段序列

**状态**：在用（可改）
**一句话**：`Path` 是段序列（名字或整数索引），是普通值；两个消费者是 `Json.at` 和 `Fs.read`，渲染由方法决定。

**动机**：路径能存、能传、能算，不是靠字符串拼。`let key = user:name` 之后可以 `config.at key`、`keys.map {it.name}`。同一份路径字面量既能寻址 JSON 也能寻址文件系统，两个宿主共享一个类型。

**形态**：

```
let p = user:name
let q = data:0:items        # 整数段是索引
let r = :usr:local:bin      # 前导冒号：绝对路径

p.os        # 用 / 连接
p.json      # 用 . 与 [i]
Path.of ["a.b"]        # 带点/空格/转义的键
Path.parse "./data.txt"  # 来自外部字符串
```

字面量只吃标识符与整数；其他键走 `Path.of`。

**代价**：

- **`:` 的三种用法挤在一起**：记录字段、类型标注、路径字面量都用 `:`，读代码时 `x: Int` 与 `x:y` 要靠上下文分。
- **不归一化**：大小写、`..`、Windows 分隔符都不处理，语义留给宿主——`a:..:b` 在各宿主上不一样。
- **与查询的分界要守**：一旦加通配，路径就从「定位」变成「查询」，结果形状随段而变。
