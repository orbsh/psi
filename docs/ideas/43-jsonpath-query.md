# JsonPath 式查询

**状态**：候选
**一句话**：Path 支持通配 `*`、递归 `..`、过滤 `?()`，一次取出一组值——`users:*:name` 直接返回 `List<Json>`。

**动机**：边界数据最常做的事是「把这一批东西里的某个键都拿出来」。没有查询子集，就得 `match` 出形状再手写遍历，五行动作写成十五行。JSONPath / jq 的流行证明这个需求真实存在。

**形态**（若采用）：

```
users:*:name
data:..:id
items:?{it.active}:name
```

**代价**：

- **结果类型随段而变**：定位返回 `Json`，通配返回 `List<Json>`，递归返回更宽的东西。取值处读不出形状，只能从类型推断或显式标注。
- **两种语义一个类型**：Path 从「一个指针」变成「一个小程序」，`config.at p` 的语义要按 p 里面有没有通配分岔。
- **编译期不可知**：过滤是个谓词，`?{it.active}` 里 `it` 的类型是 `Json`，谓词能做的事被 `Json` 的形状限死。

折中：通配与查询不进 `Path`，另立 `Query` 类型（结果固定是 `List<Json>`），两类型各自语义单一。
