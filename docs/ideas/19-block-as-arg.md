# 尾块是普通实参

**状态**：在用（可改）
**一句话**：`xs.map {x| x * 2}` 里的块就是一个 primary，站实参位；不存在「块绑定最近一次调用」这条规则。

**动机**：Ruby 和 Scala 都需要一条专门规则说明尾块属于谁，因为那里的块有特殊语法位置。如果块只是 primary，规则数归零——同一个 arity 分组规则解释了它。

**形态**：块的三种形态由内容区分，不由位置区分。

```
{x| x * 2}        # 带 | 的按段数列参数
{ x | x * 2 }     # 同上，空白无关
x: 1, y: 2        # 带 : 的是记录字面量（花括号里）
{ do_thing }      # 其余是块；体里出现 it 就是单参块
{ it.trim }       # 单参块，参数名 it
```

**代价**：块与记录字面量要靠内容区分，`{ x: 1 }` 是记录、`{ x }` 是块——一个字符之差，错误信息要好。另外没有尾块语法糖，`each do |x| ... end` 那种视觉节奏不存在。

**冲突**：[12](12-arity-grouping.md)（块是 primary 是它的规则之一）。若 [17](17-currying.md) 成立，块与函数值合一，这条的表述要改但结构不变。
