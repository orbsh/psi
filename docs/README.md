# 文档结构

```
docs/
  ideas/         一个想法一份文档；允许互相冲突，没有终态
  reference/     纯参考件（语法总表、示例程序），不承载判断
  design.md      拆分前的长文，保留备查
```

## 读法

- 想改一处设计：找到那条想法对应的文档，改它。不需要动别的文档，也不要求全局一致。
- 想知道某处「为什么这么写」：看那份文档的「代价」节，那里只写开销，不写裁决。
- 想知道有什么可选做法：看 `ideas/` 里成对出现的文档（如 14/15、16/17、23/24、31/32、33/34、54/55/56）。
- `design.md` 与新文档冲突时，以 `ideas/` 为准；`design.md` 是历史快照，不再维护。
